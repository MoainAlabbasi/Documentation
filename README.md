## 📋 نظرة عامة على المشروع

**اسم المشروع:** نظام إدارة المحتوى الأكاديمي الذكي (Smart Academic Content Management - S-ACM)

**الوصف:** منصة ويب متكاملة لإدارة المحتوى الأكاديمي في جامعة العلوم والتكنولوجيا - فرع الحديدة. تخدم ثلاث فئات من المستخدمين (طالب، مدرس، مسؤول) وتوفر وظائف ذكاء اصطناعي لتلخيص المحاضرات وتوليد الأسئلة.

**نوع المشروع:** مشروع تخرج جامعي

**إشراف:** د/ نوال الرجوي
