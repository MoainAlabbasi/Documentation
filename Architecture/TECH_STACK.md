# 🛠️ TECH_STACK - التقنيات المستخدمة

> **⚠️ تعليمات:** هذا الملف يوثق جميع التقنيات والأدوات المستخدمة في المشروع. يجب تحديثه عند إضافة أي تقنية جديدة.

---

## الخلفية البرمجية (Backend)

| التقنية | الإصدار | الغرض |
| :--- | :--- | :--- |
| **Python** | 3.11+ | لغة البرمجة الأساسية |
| **Django** | 5.x | إطار العمل الرئيسي للتطبيق |
| **Django REST Framework** | (اختياري) | لبناء واجهات برمجة التطبيقات (APIs) إذا لزم الأمر |
| **PostgreSQL** | 15+ | قاعدة البيانات العلائقية |
| **Gunicorn** | (للإنتاج) | خادم WSGI لتشغيل التطبيق في بيئة الإنتاج |

| التقنية | الإصدار | الغرض |
