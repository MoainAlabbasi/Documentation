# Documentation - توثيق مشروع نظام إدارة المحتوى الأكاديمي الذكي

## نظرة عامة
هذا المستودع يحتوي على توثيق مشروع التخرج **نظام إدارة المحتوى الأكاديمي الذكي (S-ACM)**. يتم توفير أحدث النسخ للوصول السريع، مع الاحتفاظ بأرشيف مؤرخ لكل إصدار.
