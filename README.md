# Documentation - توثيق مشروع نظام إدارة المحتوى الأكاديمي الذكي

## نظرة عامة
هذا المستودع يحتوي على توثيق مشروع التخرج **نظام إدارة المحتوى الأكاديمي الذكي (S-ACM)** المقدم من طلاب قسم تقنية المعلومات في كلية الحاسبات وتكنولوجيا المعلومات - جامعة العلوم والتكنولوجيا، فرع الحديدة.

## وصف المشروع

نظام S-ACM هو منصة رقمية متكاملة تهدف إلى:
- تسهيل رفع وتنظيم المواد الدراسية
- توفير نظام إشعارات ذكي
- دمج وظائف الذكاء الاصطناعي (تلخيص المحاضرات وتوليد الأسئلة)
- تعزيز التواصل بين الطلاب وأعضاء هيئة التدريس

## التقنيات المستخدمة

- **Backend:** Python (Django Framework)
- **Database:** PostgreSQL
- **Frontend:** Django Templates + Bootstrap 5 + HTMX
- **AI:** TensorFlow, PyTorch, NLTK
